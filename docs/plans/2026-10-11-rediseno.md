# Rediseño de Pulse: plan de implementación

> **Para agentes:** SUB-SKILL REQUERIDA: usa superpowers:subagent-driven-development (recomendado) o superpowers:executing-plans para ejecutar este plan tarea por tarea. Los pasos usan casillas (`- [ ]`) para el seguimiento.

**Objetivo:** llevar Pulse a la dirección Grafito del spec `docs/specs/2026-10-11-rediseno.md`: base visual compartida con tema claro/oscuro, ícono de bandeja de tres puntos con flyout propio en el clic derecho, isla rediseñada (Comando y Orbe), Bolsillo nuevo y Mosaico con Inicio, Sesiones, Hoy, Bitácora y Ajustes completos.

**Arquitectura:** los tokens de color viven como variables CSS en `app/ui/src/shared/base.css`, con la versión clara bajo `:root[data-theme="light"]`. Los controles (botón, tecla, interruptor, segmentado, deslizador, muestras, chips, puntos) son clases CSS en `shared/ui.css`, que usan por igual la isla (TypeScript sin framework) y las ventanas React (Bolsillo, flyout, Mosaico) a través de envoltorios en `shared/ui.tsx`. La lógica que se puede probar (textos, orden, avisos, rutas, filtros) va en módulos puros con pruebas de Vitest; el núcleo en Rust gana dos ajustes, un ícono nuevo, una ventana nueva y un comando de bitácora.

**Stack:** Tauri 2.12, Rust (serde, windows-sys), TypeScript 5.6, React 18.3, Tailwind 4.1, Vite 5.4, Vitest 2.1.

**Fuentes de verdad:** el spec (qué debe quedar) y los artboards de `docs/artboards/rediseno/` (medidas y estructura exactas; ver su `README.md`). Donde un artboard use `--acc`, `--onacc`, `--accpress` o un `--sel` con tinte verde, manda el spec §2: no hay color de marca, así que `--acc` → `--tx`, `--onacc` → `--surface` y `--sel` es el gris del spec. Las fuentes de los artboards se sustituyen por Hanken Grotesk (interfaz) y Geist Mono (código y cifras).

## Restricciones globales

- Textos de la interfaz en español. Comentarios del código en español, como el resto del repo.
- Commits locales, mensajes en inglés, sin líneas de atribución ni co-autoría. No hacer push.
- `pulse.exe` y `crates/` no se tocan: nada de este plan cambia las reglas de `CLAUDE.md` sobre `pulse emit`, `pulse ask` ni el instalador.
- `#[serde(default)]` en toda estructura de configuración: un `config.json` viejo tiene que seguir cargando.
- `prefers-reduced-motion` en todas las ventanas: sin estiramientos ni viajes; cambios por opacidad en 120 ms; la línea de "Mantener" sigue avanzando.
- Ningún estado depende solo del color: siempre hay icono o forma de punto.
- Contraste de texto 4.5:1 sobre `surface` en ambos temas (por eso `tx3` es `#7d827d` / `#676d67`).
- Botones reales (`<button>`), `aria-label` en los de solo icono, foco visible con `outline` de 2 px en `tx2`.
- La isla y sus avisos van siempre en la versión oscura; `appearance.theme` solo cambia Bolsillo, el flyout y Mosaico (spec §13).
- Nada de botones en píldora; los interruptores sí son píldora (spec §2.5).
- Comandos de verificación (desde la raíz del repo):
  - `cargo test --workspace`
  - `npm test --prefix app`
  - `npx --prefix app tsc --noEmit -p app/tsconfig.json`
  - Prueba a mano: `npm run tauri dev --prefix app` y, en otra terminal, `pwsh scripts/demo.ps1` (sin argumentos lista los escenarios; requiere haber corrido `pwsh scripts/install.ps1` alguna vez para tener `pulse.exe`).

## Decisiones técnicas (alternativas y qué se pierde)

El usuario es nuevo en Rust y Tauri; estas son las elecciones del plan y lo que cada alternativa daría o quitaría. Si alguna no convence, se cambia antes de empezar la tarea que la usa.

| Tema | Elegido | Alternativa | Qué se gana / qué se pierde |
|---|---|---|---|
| Flyout del clic derecho | Ventana webview con **React** (como Bolsillo) | TypeScript sin framework (como la isla) | React reutiliza los interruptores, `useConfig` y `useSnapshot`; cuesta ~140 KB de JS que se cargan una sola vez al arrancar. Sin framework sería más liviano, pero duplicaría controles y lógica. |
| Cuándo se crea el flyout | Al arrancar, oculto | Al primer clic (como Bolsillo hoy) | El primer clic derecho es instantáneo. Cuesta un proceso de renderizado de WebView2 más en memoria (~20–30 MB) todo el tiempo. |
| Alto del flyout | La interfaz mide su contenido y llama `flyout_fit(alto)` | Alto fijo | La fila "Responder permiso" aparece y desaparece; con alto fijo quedaría una franja transparente que no cierra el menú al hacer clic. |
| Navegación de Mosaico | Estado de React + `location.hash` (`#sesiones/<id>`, `#ajustes/pulsos`) | react-router | Cero dependencias nuevas y basta para cinco pantallas. Se pierden rutas anidadas y cargadores, que no hacen falta. |
| Tema claro/oscuro | Variables CSS + atributo `data-theme` en `<html>`; Tailwind las lee con `@theme inline` | Variante `dark:` de Tailwind | Una sola fuente de colores para la isla (sin Tailwind) y las ventanas React. Con `dark:` habría que duplicar cada clase y la isla no podría usarlo. |
| Controles compartidos | Clases CSS en `shared/ui.css` + envoltorios React finos | Componentes solo con utilidades de Tailwind | La isla necesita los mismos botones y teclas y no usa Tailwind. |
| Hanken Grotesk | Archivo `woff2` descargado una vez a `app/ui/fonts/` (como Geist hoy) | Dependencia npm `@fontsource-variable/hanken-grotesk` | Sin dependencia en tiempo de ejecución ni en el `package.json`. Actualizarla es volver a descargar el archivo. |
| Ícono de la bandeja | Se dibuja en Rust, píxel por píxel (como el anillo de hoy) | PNG por cada combinación | Con tres sesiones y cuatro formas hay demasiadas combinaciones para archivos. |
| Ruta inicial de Mosaico al crearlo | `initialization_script` que define `window.__pulseRoute` | `#hash` en la URL de `WebviewUrl::App` | Tauri puede codificar el `#` dentro de la ruta del archivo; el script de inicio llega siempre antes que la página. |

```ts
// Tema de las ventanas (Bolsillo, flyout, Mosaico): la versión oscura o clara de Grafito. La isla no lo usa.
export type ThemePref = 'dark' | 'light' | 'system';
/** "system" sigue el modo de Windows (WebView2 lo expone como prefers-color-scheme). */
export const resolveTheme = (pref: ThemePref | undefined, systemLight: boolean): 'dark' | 'light' =>
  pref === 'light' || (pref === 'system' && systemLight) ? 'light' : 'dark';
const mq = () => matchMedia('(prefers-color-scheme: light)');
export function applyTheme(pref: ThemePref | undefined, root: HTMLElement = document.documentElement) { root.dataset.theme = resolveTheme(pref, mq().matches); }
/** Aplica el tema y lo vuelve a aplicar si cambia el modo de Windows. Devuelve cómo dejar de seguirlo. */
export function followTheme(pref: ThemePref | undefined): () => void {
  applyTheme(pref);
  const m = mq(), f = () => applyTheme(pref);
  m.addEventListener('change', f);
  return () => m.removeEventListener('change', f);
}
```

En `react.ts`, importa `followTheme` y agrega:

```ts
/** Aplica `appearance.theme` a esta ventana y lo sigue mientras cambie. */
export function useTheme(cfg: Config | null) {
  const pref = cfg?.appearance?.theme;
  useEffect(() => followTheme(pref), [pref]);
}
```

```rust
use crate::state::{Session, SessionState};
use std::sync::Mutex;

#[derive(Debug, Clone, Copy, PartialEq)] pub enum DotShape { Fill, Halo, Ring }
pub type TrayDot = (DotShape, [u8; 3]);
const TX: [u8; 3] = [234, 237, 234];
const PERM: [u8; 3] = [227, 176, 92];
const DONE: [u8; 3] = [143, 195, 160];
const CALM: [u8; 3] = [158, 163, 158];

/// Un punto por sesión (hasta tres, en orden de llegada) con las formas de la isla (spec §5). Sin sesiones: un anillo gris.
pub fn tray_dots(sessions: &[Session]) -> Vec<TrayDot> {
    if sessions.is_empty() { return vec![(DotShape::Ring, CALM)]; }
    let mut v: Vec<&Session> = sessions.iter().collect();
    v.sort_by_key(|s| s.slot);
    v.iter().take(3).map(|s| match s.state {
        SessionState::Working => (DotShape::Fill, TX),
        SessionState::Waiting => (DotShape::Halo, PERM),
        SessionState::Done => (DotShape::Ring, DONE),
        SessionState::IdleWait | SessionState::Idle => (DotShape::Ring, CALM),
    }).collect()
}

/// Dibuja los puntos centrados en un ícono cuadrado de `size` px (RGBA, con borde suavizado).
pub fn dots_rgba(size: u32, dots: &[TrayDot]) -> Vec<u8> {
    let s = size as f32; let n = dots.len().max(1) as f32;
    let (r, gap, ring) = (s * 0.15, s * 0.33, s * 0.06);   // en 32 px: radio 4.8, centros a 10.6, anillo de 1.9
    let x0 = s / 2.0 - gap * (n - 1.0) / 2.0;
    let mut px = vec![0u8; (size * size * 4) as usize];
    for (i, (shape, rgb)) in dots.iter().enumerate() {
        let (cx, cy) = (x0 + gap * i as f32, s / 2.0);
        for y in 0..size { for x in 0..size {
            let d = ((x as f32 + 0.5 - cx).powi(2) + (y as f32 + 0.5 - cy).powi(2)).sqrt();
            let a = match shape {
                DotShape::Fill => (r - d + 0.5).clamp(0.0, 1.0),
                DotShape::Halo => (r - d + 0.5).clamp(0.0, 1.0).max(0.35 * (r * 1.45 - d + 0.5).clamp(0.0, 1.0)),
                DotShape::Ring => ((d - (r - ring)).min(r - d) + 0.5).clamp(0.0, 1.0),
            };
            let o = ((y * size + x) * 4) as usize;
            if a > 0.0 && a * 255.0 > px[o + 3] as f32 { px[o..o + 3].copy_from_slice(rgb); px[o + 3] = (a * 255.0) as u8; }
        } }
    }
    px
}
```

```ts
/** Siguiente fila con flechas: salta las deshabilitadas y da la vuelta. `from` = -1 si no hay ninguna elegida. */
export function step(enabled: boolean[], from: number, dir: 1 | -1): number {
  const n = enabled.length;
  if (!enabled.some(Boolean)) return -1;
  let i = from < 0 ? (dir > 0 ? -1 : n) : from;
  for (let k = 0; k < n; k++) { i = (i + dir + n) % n; if (enabled[i]) return i; }
  return from;
}
```

```rust
/// Flyout del clic derecho: 300 px de menú con 12 px de margen transparente alrededor para su sombra.
pub const FLYOUT_W: f64 = 324.0;
static FLYOUT_HIDDEN_AT: std::sync::atomic::AtomicI64 = std::sync::atomic::AtomicI64::new(0);
/// X lógica del último clic derecho en la bandeja: el flyout se centra sobre ella.
static FLYOUT_CLICK_X: Mutex<f64> = Mutex::new(0.0);

/// Esquina superior izquierda del flyout (lógica): centrado sobre el clic, encima de la barra de tareas y dentro del área de trabajo.
pub fn flyout_origin(click_x: f64, size: (f64, f64), work: (f64, f64, f64, f64)) -> (f64, f64) {
    let ((w, h), (l, t, r, b)) = (size, work);
    ((click_x - w / 2.0).clamp(l, (r - w).max(l)), (b - h).max(t))
}
/// Se crea al arrancar, oculto, para que el primer clic derecho sea instantáneo.
pub fn create_flyout(app: &AppHandle) -> tauri::Result<()> {
    let w = WebviewWindowBuilder::new(app, "flyout", WebviewUrl::App("flyout.html".into()))
        .transparent(true).decorations(false).always_on_top(true).skip_taskbar(true).resizable(false).shadow(false)
        .inner_size(FLYOUT_W, 420.0).visible(false).build()?;
    let w2 = w.clone();
    w.on_window_event(move |e| if let tauri::WindowEvent::Focused(false) = e {
        if w2.is_visible().unwrap_or(false) { FLYOUT_HIDDEN_AT.store(crate::now_ms(), std::sync::atomic::Ordering::SeqCst); }
        let _ = w2.hide();
    });
    Ok(())
}
fn place_flyout(win: &tauri::WebviewWindow) {
    let scale = win.scale_factor().unwrap_or(1.0);
    let Ok(size) = win.inner_size() else { return };
    let (l, t, r, b) = work_area();
    let (x, y) = flyout_origin(*FLYOUT_CLICK_X.lock().unwrap(), (size.width as f64 / scale, size.height as f64 / scale), (l / scale, t / scale, r / scale, b / scale));
    let _ = win.set_position(tauri::LogicalPosition::new(x, y));
}
pub fn toggle_flyout(app: &AppHandle, click: tauri::PhysicalPosition<f64>) {
    use tauri::Emitter;
    let Some(win) = app.get_webview_window("flyout") else { return };
    if win.is_visible().unwrap_or(false) { let _ = win.hide(); return; }
    // el clic en la bandeja que le quitó el foco no debe volver a abrirlo
    if crate::now_ms() - FLYOUT_HIDDEN_AT.load(std::sync::atomic::Ordering::SeqCst) < 300 { return; }
    *FLYOUT_CLICK_X.lock().unwrap() = click.x / win.scale_factor().unwrap_or(1.0);
    place_flyout(&win);
    let _ = app.emit_to("flyout", "pulse://flyout-open", ());
    let _ = win.show(); let _ = win.set_focus();
}
/// La interfaz avisa su alto (cambia con la fila "Responder permiso"); se recoloca para que el borde de abajo no se mueva.
pub fn fit_flyout(app: &AppHandle, height: f64) {
    let Some(win) = app.get_webview_window("flyout") else { return };
    let _ = win.set_size(tauri::LogicalSize::new(FLYOUT_W, height.ceil()));
    place_flyout(&win);
}
pub fn hide_flyout(app: &AppHandle) { if let Some(w) = app.get_webview_window("flyout") { let _ = w.hide(); } }
```

```tsx
import { useEffect, useLayoutEffect, useRef, useState } from 'react';
import { flyoutFit, flyoutHide, muteSession, onFlyoutOpen, openDashboard, openPalette, quit, setFocus, type Config } from '../shared/bridge';
import { statusLine, topDot } from '../shared/format';
import { useConfig, useSnapshot, useTheme } from '../shared/react';
import { Dot, Icon, Keys } from '../shared/ui';
import { step } from './menu';

type Item = { id: string; icon: string; label: string; keys?: string[]; on?: boolean; disabled?: boolean; run: () => void };

export function Flyout() {
  const snap = useSnapshot(), [cfg, save] = useConfig();
  useTheme(cfg);
  const [open, setOpen] = useState(0);   // cambia en cada apertura: reinicia la animación y la selección
  const box = useRef<HTMLDivElement>(null);
  useEffect(() => { let off: (() => void) | undefined; onFlyoutOpen(() => setOpen(n => n + 1)).then(f => (off = f)); return () => off?.(); }, []);

  const now = Date.now();
  const perm = snap.pending.some(p => p.kind === 'permission');
  const allMuted = snap.sessions.length > 0 && snap.sessions.every(s => s.muted_until_ms > now);
  const close = () => { (document.activeElement as HTMLElement | null)?.blur(); flyoutHide(); };
  const toggle = <K extends 'sounds' | 'pulses' | 'keyboard'>(c: Config, k: K) => save({ ...c, [k]: { ...c[k], enabled: !c[k].enabled } });
  const groups: Item[][] = !cfg ? [] : [
    [
      ...(perm ? [{ id: 'perm', icon: 'front_hand', label: 'Responder permiso', keys: ['Ctrl', 'Alt', 'Espacio'], run: () => { openPalette(); close(); } }] : []),
      { id: 'open', icon: 'open_in_new', label: 'Abrir Pulse', run: () => { openDashboard(); close(); } },
      { id: 'mute', icon: allMuted ? 'notifications_active' : 'notifications_paused', label: allMuted ? 'Quitar silencio' : 'Silenciar 30 min', disabled: !snap.sessions.length,
        run: () => { snap.sessions.forEach(s => muteSession(s.id, allMuted ? 0 : 30)); close(); } },
    ],
    [
      { id: 'focus', icon: 'dark_mode', label: 'Modo foco', on: snap.focus, run: () => setFocus(!snap.focus) },
      { id: 'sounds', icon: 'volume_up', label: 'Sonidos', on: cfg.sounds.enabled, run: () => toggle(cfg, 'sounds') },
      { id: 'pulses', icon: 'blur_on', label: 'Pulsos en los bordes', on: cfg.pulses.enabled, run: () => toggle(cfg, 'pulses') },
      { id: 'keyboard', icon: 'keyboard', label: 'Teclado', on: cfg.keyboard.enabled, run: () => toggle(cfg, 'keyboard') },
    ],
    [
      { id: 'settings', icon: 'settings', label: 'Ajustes', run: () => { openDashboard('ajustes'); close(); } },
      { id: 'quit', icon: 'power_settings_new', label: 'Salir', run: () => quit() },
    ],
  ];
  const items = groups.flat();

  // el núcleo ajusta la ventana a lo que mide el menú (más el margen de 12 px para la sombra)
  useLayoutEffect(() => { if (box.current) flyoutFit(box.current.offsetHeight + 24); }, [items.length]);

  // flechas entre filas (Enter y Espacio los resuelve el botón enfocado), Esc cierra
  useEffect(() => {
    const onKey = (e: KeyboardEvent) => {
      if (e.key === 'Escape') { e.preventDefault(); close(); return; }
      if (e.key !== 'ArrowDown' && e.key !== 'ArrowUp') return;
      e.preventDefault();
      const rows = [...(box.current?.querySelectorAll<HTMLElement>('.mi') ?? [])];
      const next = step(items.map(i => !i.disabled), rows.indexOf(document.activeElement as HTMLElement), e.key === 'ArrowDown' ? 1 : -1);
      rows[next]?.focus();
    };
    window.addEventListener('keydown', onKey);
    return () => window.removeEventListener('keydown', onKey);
  }, [items]);

  if (!cfg) return null;
  let i = -1;
  return <div className="fly-wrap">
    <div key={open} ref={box} role="menu" aria-label="Pulse" className="fly surf">
      <div className="fly-head"><b>Pulse</b><span><Dot kind={topDot(snap)} />{statusLine(snap)}</span></div>
      {groups.map((g, gi) => <div key={gi}>
        <div className="sep" />
        {g.map(it => { i++; const toggleRow = it.on !== undefined;
          return <button key={it.id} type="button" className="mi" data-i={i} role={toggleRow ? 'menuitemcheckbox' : 'menuitem'} aria-checked={toggleRow ? it.on : undefined}
            aria-disabled={it.disabled || undefined} onClick={() => { if (!it.disabled) it.run(); }}>
            <Icon name={it.icon} /><span>{it.label}</span>
            {toggleRow ? <span className={`sw sm ${it.on ? 'on' : ''}`} aria-hidden="true" /> : it.keys ? <Keys k={it.keys} /> : <span />}
          </button>; })}
      </div>)}
    </div>
  </div>;
}
```

```ts
  if (s.state === 'Done') return { text: `Terminó hace ${since(now - s.since_ms)}`, mono: false };

  return { text: s.last + (s.subagents ? ` · ${s.subagents} subagente${s.subagents > 1 ? 's' : ''}` : ''), mono: true };
```

```ts
// Lógica pura de la isla (sin DOM): avisos, cola de permisos, preguntas. Probada en model.test.ts.
import type { Deferred, Fx, Pending } from '../shared/bridge';
import { COLORS, dur, hhmm } from '../shared/format';

/** Aviso breve (spec §3.4): `who` en negrita, `what` en tx2, `extra` en monoespaciada; `items` = "mientras estabas en foco". */
export interface Notice { id: number; icon: string; color: string; who?: string; what: string; extra?: string; life: number; items?: Deferred[] }
let seq = 0;
const N = (n: Omit<Notice, 'id'>): Notice => ({ id: ++seq, ...n });

export function toNotice(fx: Fx): Notice | null {
  const [head, ...rest] = fx.text.split('|'), tail = rest.join('|');
  switch (fx.kind) {
    case 'done': return fx.visual ? N({ icon: 'check', color: COLORS.done, who: fx.project, what: 'terminó', extra: fx.text ? dur(Number(fx.text)) : undefined, life: 2800 }) : null;
    case 'error': return fx.visual ? N({ icon: 'error', color: COLORS.error, who: fx.project, what: 'falló', extra: fx.text || undefined, life: 2800 }) : null;
    case 'notice': return head === 'plan'
      ? N({ icon: 'assignment', color: COLORS.idle, who: fx.project, what: 'terminó un plan, revísalo en la terminal', life: 4500 })
      : N({ icon: 'help', color: COLORS.idle, who: fx.project, what: `te pregunta en la terminal: ${tail}`, life: 4500 });
    case 'release': return N({ icon: 'dark_mode', color: COLORS.idle, what: 'Mientras estabas en foco', items: JSON.parse(fx.text) as Deferred[], life: 4000 });
    case 'resolved':
      switch (head) {
        case 'allow': return N({ icon: 'check', color: COLORS.done, what: 'Permitido', extra: tail, life: 1300 });
        case 'deny': return N({ icon: 'close', color: COLORS.error, what: 'Denegado', extra: tail, life: 1300 });
        case 'answer': return N({ icon: 'send', color: COLORS.idle, what: `Respuesta enviada: ${tail}`, life: 1800 });
        case 'skip': return N({ icon: 'terminal', color: COLORS.idle, what: 'Respóndela en la terminal', life: 1800 });
        case 'terminal': return N({ icon: 'terminal', color: COLORS.idle, what: 'Respondido en la terminal', life: 1600 });
        case 'none': return N({ icon: 'schedule', color: COLORS.permission, what: 'Sin respuesta: Claude te pregunta en la terminal', life: 2200 });
      }
      return null;
  }
  return null;
}

/** "Quiere ejecutar" para la terminal, "Quiere usar" para el resto de herramientas. */
export const verb = (tool: string, lower = false) => { const v = tool === 'Bash' || tool === 'PowerShell' ? 'Quiere ejecutar' : 'Quiere usar'; return lower ? v.toLowerCase() : v; };

/** Varios pendientes: posición ("1 de 3") y quién sigue (spec §3.3). */
export function queueInfo(pending: Pending[]): { pos: string; next: string; nextCmd: string } | null {
  if (pending.length < 2) return null;
  const n = pending[1];
  return { pos: `1 de ${pending.length}`, next: `Siguiente: ${n.project} ${n.kind === 'question' ? 'te pregunta' : verb(n.tool, true)}`, nextCmd: n.kind === 'question' ? '' : n.command };
}

const REL: Record<string, [string, string, string]> = {
  done: ['check', COLORS.done, 'terminó'], error: ['error', COLORS.error, 'falló una herramienta'], idle: ['hourglass', COLORS.idle, 'te espera'],
  permission: ['front_hand', COLORS.permission, 'pidió permiso'], start: ['play_arrow', COLORS.idle, 'empezó'], subagent: ['account_tree', COLORS.subagent, 'terminó un subagente'],
};
/** Una fila de "Mientras estabas en foco": icono, proyecto, qué pasó y a qué hora. */
export function releaseRow(d: Deferred) { const [icon, color, what] = REL[d.kind] ?? ['info', COLORS.idle, d.kind]; return { icon, color, project: d.project, text: `${what} · ${hhmm(d.at_ms)}` }; }

/** Texto a la izquierda de la barra de una pregunta. */
export const qHint = (multi: boolean, optionCount: number, chosen: number) => multi ? (chosen === 1 ? '1 elegida' : `${chosen} elegidas`) : `1 a ${Math.min(9, optionCount)} para elegir`;
/** Tecla 1–9 → índice de opción, o -1. */
export const digitIndex = (key: string, count: number) => { const n = Number(key); return /^[1-9]$/.test(key) && n <= Math.min(9, count) ? n - 1 : -1; };

export const PAL_EMPTY = 'Nada coincide. Prueba con "foco", "silenciar" o el nombre de un proyecto.';
```

```ts
/** Coincidencia aproximada de la paleta: letras en orden, sin acentos; las coincidencias van en negrita. */
export function fuzzy(text: string, query: string): { ok: boolean; html: string } {
  if (!query) return { ok: true, html: esc(text) };
  const t = norm(text), qq = norm(query); let i = 0, out = '';
  for (let k = 0; k < text.length; k++) { if (i < qq.length && t[k] === qq[i]) { out += `<b>${esc(text[k])}</b>`; i++; } else out += esc(text[k]); }
  return { ok: i === qq.length, html: out };
}
```

```ts
export interface Row { id: string; project: string; state: SessionState; dot: DotKind; what: string; mono: boolean; since: number; need: boolean; pendingId?: number }
const RANK: Record<SessionState, number> = { Waiting: 0, IdleWait: 1, Working: 2, Done: 3, Idle: 4 };
/** Sesiones en orden de urgencia (la que te necesita primero) y, a igual urgencia, por orden de llegada. */
export function sessionRows(s: Snapshot, now: number): Row[] {
  return [...s.sessions].sort((a, b) => RANK[a.state] - RANK[b.state] || a.slot - b.slot).map(x => {
    const p = s.pending.find(q => q.session_id === x.id), w = sessionWhat(x, p, now);
    return { id: x.id, project: x.project, state: x.state, dot: p ? 'halo' : dotKind(x.state), what: w.text, mono: w.mono, since: x.since_ms, need: !!p, pendingId: p?.id };
  });
}
```

```ts
export type Side = 'left' | 'center' | 'right';
/** Al soltar el Orbe: la zona más cercana según la x (0 a 1) de su centro. */
export const nearestZone = (x: number): Side => x < 1 / 3 ? 'left' : x > 2 / 3 ? 'right' : 'center';
/** Forma del Orbe en reposo (spec §3.2): luna en foco, anillo casi transparente sin sesiones; si no, la sesión más urgente. */
export function orbDot(s: Snapshot): DotKind | 'moon' | 'none' {
  if (s.focus) return 'moon';
  if (!s.sessions.length) return 'none';
  const has = (st: SessionState) => s.sessions.some(x => x.state === st);
  return s.pending.length || has('Waiting') ? 'halo' : has('Working') ? 'fill' : has('Done') ? 'done' : 'calm';
}
```

```ts
// Línea de tiempo del día (de medianoche a ahora): marcas de hora. Las barras vienen de daily_summary.
import { hhmm } from './format';
export const dayStart = (now: number) => { const d = new Date(now); d.setHours(0, 0, 0, 0); return d.getTime(); };
/** 00:00, 06:00, 12:00 y 18:00 si ya pasaron (y no chocan con la última), y la hora actual al final. Posición de 0 a 1. */
export function ticks(now: number): [number, string][] {
  const span = Math.max(1, now - dayStart(now)), out: [number, string][] = [];
  for (const h of [0, 6, 12, 18]) { const f = (h * 3_600_000) / span; if (h === 0 || f < 0.92) out.push([f, `${String(h).padStart(2, '0')}:00`]); }
  out.push([1, hhmm(now)]);
  return out;
}
```

```ts
// Rutas de Mosaico en el hash: "inicio", "sesiones/<id>", "hoy", "bitacora", "ajustes/<sección>".
export type Screen = 'inicio' | 'sesiones' | 'hoy' | 'bitacora' | 'ajustes';
export interface Route { screen: Screen; arg?: string }
const SCREENS: Screen[] = ['inicio', 'sesiones', 'hoy', 'bitacora', 'ajustes'];
export function parseRoute(h: string | null | undefined): Route {
  const [s, ...rest] = (h ?? '').replace(/^#/, '').split('/');
  const screen = (SCREENS as string[]).includes(s) ? s as Screen : 'inicio', arg = rest.join('/');
  return screen !== 'inicio' && arg ? { screen, arg } : { screen };
}
export const formatRoute = (r: Route) => r.arg ? `${r.screen}/${r.arg}` : r.screen;
```

```tsx
declare global { interface Window { __pulseRoute?: string } }

/** Ruta actual: la que dejó el núcleo al crear la ventana, la del hash o la que llega por `pulse://route`. */
function useRoute(): [Route, (r: Route) => void] {
  const [route, set] = useState<Route>(() => parseRoute(window.__pulseRoute || location.hash));
  const go = (r: Route) => { set(r); history.replaceState(null, '', '#' + formatRoute(r)); };
  useEffect(() => { let off: (() => void) | undefined; onRoute(v => go(parseRoute(v))).then(f => (off = f)); return () => off?.(); }, []);
  return [route, go];
}

const NAV: [Screen, string, string][] = [['inicio', 'home', 'Inicio'], ['sesiones', 'stacks', 'Sesiones'], ['hoy', 'schedule', 'Hoy']];
```

```rust
/// Un evento de hoy para la Bitácora de Mosaico.
#[derive(Debug, Clone, Serialize, PartialEq)]
pub struct LogItem { pub at_ms: i64, pub session_id: String, pub project: String, pub kind: String, pub text: String }

/// Qué pasó, en palabras. `None` si la línea no es un evento conocido.
fn describe(e: &serde_json::Value) -> Option<(String, String)> {
    let kind = e["kind"].as_str()?;
    let s = |k: &str| e[k].as_str().unwrap_or("").to_string();
    let text = match kind {
        "start" => format!("Prompt: {}", s("prompt")),
        "tool" => { let t = s("target"); if t.is_empty() { s("tool") } else { format!("{} {t}", s("tool")) } }
        "permission" => format!("Permiso: {}", s("command")),
        "question" => format!("Pregunta: {}", e["questions"][0]["question"].as_str().unwrap_or("")),
        "resolve" => match e["decision"].as_str() { Some("allow") => "Permitido".into(), Some("deny") => "Denegado".into(), _ => "Sin respuesta en Pulse".into() },
        "done" => "Terminó".into(),
        "idle" => "Te espera".into(),
        "plan" => "Plan listo para revisar".into(),
        "error" => format!("Falló: {}", s("message")),
        "subagent-start" => format!("Subagente: {}", s("agent")),
        "subagent-stop" => format!("Subagente terminó: {}", s("agent")),
        "session-start" => "Sesión abierta".into(),
        "session-end" => "Sesión cerrada".into(),
        _ => return None,
    };
    Some((kind.to_string(), text))
}

/// Eventos entre `from_ms` y `to_ms`, del más nuevo al más viejo, hasta `limit`. Las líneas que no se entienden se saltan.
pub fn parse_events(lines: impl Iterator<Item = String>, from_ms: i64, to_ms: i64, limit: usize) -> Vec<LogItem> {
    let mut out: Vec<LogItem> = lines.filter_map(|l| {
        let v: serde_json::Value = serde_json::from_str(&l).ok()?;
        let at = v["at_ms"].as_i64()?;
        if at < from_ms || at > to_ms { return None; }
        let (kind, text) = describe(&v["event"])?;
        Some(LogItem { at_ms: at, session_id: v["session_id"].as_str().unwrap_or("").into(), project: v["project"].as_str().unwrap_or("sesión").into(), kind, text })
    }).collect();
    out.sort_by(|a, b| b.at_ms.cmp(&a.at_ms));
    out.truncate(limit);
    out
}

/// Eventos de hoy (desde la medianoche local).
pub fn today(limit: usize) -> Vec<LogItem> {
    let now = crate::now_ms();
    let lines = path().and_then(|p| std::fs::read_to_string(p).ok()).unwrap_or_default();
    parse_events(lines.lines().map(str::to_string), crate::daylog::local_midnight_ms(now), now, limit)
}
```

```ts
/** Eventos de hoy para la Bitácora. Se refresca cada `every` ms y con cada cambio de estado, con un mínimo de 5 s entre llamadas. */
export function useLogToday(snap: Snapshot, every = 15_000): LogItem[] | null {
  const [d, set] = useState<LogItem[] | null>(null);
  const last = useRef(0);
  const load = useCallback(() => { last.current = Date.now(); logToday().then(set).catch(() => {}); }, []);
  useEffect(() => { load(); const t = setInterval(load, every); return () => clearInterval(t); }, [load, every]);
  useEffect(() => { if (Date.now() - last.current > 5_000) load(); }, [snap]); // eslint-disable-line react-hooks/exhaustive-deps
  return d;
}
```

```ts
// Ajustes: acabado de los pulsos, paleta pastel (spec §2.3), eventos, formas y textos.
import type { Config } from '../shared/bridge';
export type Finish = 'completo' | 'suave';
type F = Pick<Config['pulses'], 'crisp' | 'corners' | 'adapt' | 'dither'>;
const KEYS = ['crisp', 'corners', 'adapt', 'dither'] as const;
/** Suave: sin línea nítida ni grano; las esquinas y el ajuste en fondos claros siguen (spec §13). */
export const FINISH: Record<Finish, F> = { completo: { crisp: true, corners: true, adapt: true, dither: true }, suave: { crisp: false, corners: true, adapt: true, dither: false } };
/** Qué segmento marcar; `null` = las casillas no coinciden con ninguno ("Personalizado"). */
export const finishOf = (p: F): Finish | null => (Object.keys(FINISH) as Finish[]).find(k => KEYS.every(f => FINISH[k][f] === p[f])) ?? null;
export const PALETTE: [string, string][] = [['Ámbar', '#e3b05c'], ['Verde', '#8fc3a0'], ['Coral', '#e08a7e'], ['Azul', '#8fb0d6'], ['Lavanda', '#b4a6d9'], ['Arena', '#d6c49a'], ['Gris', '#b3bab5']];
export const EVENTS: [string, string][] = [['start', 'Empieza'], ['permission', 'Permiso'], ['done', 'Terminó'], ['idle', 'Te espera'], ['error', 'Error'], ['subagent', 'Subagente']];
export const SHAPES: [string, string][] = [['respira', 'Respira'], ['latido', 'Latido'], ['ola', 'Ola'], ['lateral', 'Lateral'], ['barrido', 'Barrido'], ['origen', 'Origen']];
export const seconds = (ms: number) => `${(ms / 1000).toFixed(1).replace('.', ',')} s`;
export function silentLine(per: Record<string, boolean>): string {
  const off = EVENTS.filter(([k]) => !per[k]).map(([, l]) => l);
  if (!off.length) return 'Suenan todos';
  if (off.length === EVENTS.length) return 'Ninguno suena';
  return `${off.join(', ')} ${off.length === 1 ? 'está' : 'están'} en silencio`;
}
```

## Riesgos conocidos

- **Ícono sobre barra de tareas clara:** el punto "trabaja" es casi blanco (como el anillo de hoy). Con la barra de Windows en modo claro se ve poco. No está en el spec; si molesta, se agrega luego leyendo `SystemUsesLightTheme` del registro (la característica `Win32_System_Registry` ya está en `Cargo.toml`).
- **"Activar modo foco" en la paleta:** el artboard dice "Foco por 1 hora", pero el núcleo no tiene duración de foco; la paleta dice "Activar modo foco" para no prometer algo que no pasa.
- **Teclas 1–3 y `Esc` en preguntas:** solo funcionan después de hacer clic en la tarjeta, porque la isla no le quita el teclado a la terminal al aparecer. Es intencional.
