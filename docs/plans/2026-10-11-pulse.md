# Pulse — Plan de implementación

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Construir Pulse completo según `docs/spec.md`: los hooks de Claude Code alimentan una app de escritorio que pulsa en los bordes, muestra la isla (Comando por defecto, Orbe como modo alterno), ofrece el panel Bolsillo desde la bandeja y el tablero Mosaico con bitácora, respeta el modo foco y enciende el teclado Razer.

**Architecture:** Workspace de Cargo con `pulse-protocol` (tipos y traducción de hooks), `pulse-cli` (`pulse.exe`, cliente del named pipe; `emit` y `ask`) y `app/` (Tauri v2: núcleo en Rust + interfaz Vite/TypeScript multipágina). El núcleo guarda el estado de sesiones, permisos pendientes, configuración y foco, y lo difunde a todas las ventanas con dos eventos: `pulse://state` (foto completa) y `pulse://fx` (efecto puntual). Las ventanas son: bordes (una por monitor, sin clics), isla, panel Bolsillo y tablero Mosaico.

**Tech Stack:** Rust stable MSVC · Tauri 2 (+ `tauri-plugin-global-shortcut` 2) · tokio (named pipes) · rodio 0.19 · ureq 2 (Razer Chroma REST) · windows-sys 0.59 · Vite 5 + TypeScript 5 + Vitest 2 · React 18 + Tailwind 4 (solo Bolsillo y Mosaico) · `@tauri-apps/api` 2 · PowerShell 7 para instalar.

## Global Constraints

- Windows 11, PowerShell 7, Node v24.5.0, MSVC Build Tools 14.35. Rust **no** está instalado (Task 1 lo instala).
- `pulse.exe` siempre sale con código 0. `emit` nunca escribe en stdout. `ask` solo escribe en stdout el JSON de decisión, o nada.
- `pulse.exe emit` tarda menos de 4 s en el peor caso.
- Pipe `\\.\pipe\pulse`; una línea JSON por mensaje; `v: 1`.
- Instalación en `%LOCALAPPDATA%\Pulse\` (`pulse.exe`, `pulse-app.exe`). Datos en `%USERPROFILE%\.claude\pulse\` (`config.json`, `log.jsonl`).
- Respaldo con fecha de `~/.claude/settings.json` antes de modificarlo. Se reemplazan solo entradas que llaman a `sounds/play.ps1` o a `pulse.exe`.
- Autocierre: sin sesiones vivas y 5 min sin eventos. Sesión sin eventos por 2 h = muerta.
- Isla: **un solo modo activo** (`comando` por defecto, `orbe` alterno). Nunca los dos.
- Atajos globales: `Ctrl+Alt+Y` permitir, `Ctrl+Alt+N` denegar, `Ctrl+Alt+Space` paleta. Comandos delicados se aprueban manteniendo 900 ms.
- Espera de permiso: 30 s (`ask_timeout_s`); el hook `PermissionRequest` lleva `timeout: 35`.
- Colores por evento: start `#e6eeff`, permission `#ffb02e`, done `#4fe0a0`, idle `#b6c0d4`, error `#ff5a52`, subagent `#5cc8ff`, foco `#b9a2ff`.
- Textos visibles en español. Respetar `prefers-reduced-motion` en todas las ventanas.

### Ajustes al spec descubiertos al planear (actualizar `docs/spec.md` en la Task 7)

- **"Ir a la terminal" y "Responder «continúa»" no se implementan:** los hooks no dicen en qué ventana corre cada sesión ni hay API para escribirle a Claude. Se quitan de Comando y Bolsillo.
- **Pulso "en el monitor de la sesión" → "monitor activo":** el monitor de la ventana en primer plano al llegar el evento. Opción alterna: todos los monitores.
- **"No molestar" de Windows no se detecta** (no hay API pública). El foco se activa por llamada (micrófono en uso), pantalla completa/presentación, horario, o a mano.
- La forma "Desde la terminal" nace en una posición fija por sesión (`slot` 0, 1, 2… → 18 %, 50 %, 82 % del ancho).

```rust
use serde::{Deserialize, Serialize};
use serde_json::{json, Value};

pub const PIPE_NAME: &str = r"\\.\pipe\pulse";
pub const PROTOCOL_VERSION: u32 = 1;
pub const ASK_TIMEOUT_S: u64 = 30;
const MAX_TEXT: usize = 120;

#[derive(Debug, Clone, Default, Deserialize)]
pub struct HookInput {
    pub session_id: String,
    #[serde(default)] pub cwd: String,
    pub hook_event_name: String,
    #[serde(default)] pub prompt: Option<String>,
    #[serde(default)] pub tool_name: Option<String>,
    #[serde(default)] pub tool_input: Option<Value>,
    #[serde(default)] pub notification_type: Option<String>,
    #[serde(default)] pub error: Option<String>,
    #[serde(default)] pub agent_type: Option<String>,
}

#[derive(Debug, Clone, PartialEq, Eq, Serialize, Deserialize)]
#[serde(tag = "kind", rename_all = "kebab-case")]
pub enum PulseEvent {
    SessionStart, SessionEnd,
    Start { prompt: String },
    Tool { tool: String, target: String },
    Permission { tool: String, command: String },
    Idle, Done,
    Error { message: String },
    SubagentStart { agent: String },
    SubagentStop { agent: String },
}

#[derive(Debug, Clone, PartialEq, Eq, Serialize, Deserialize)]
pub struct Envelope {
    pub v: u32,
    pub session_id: String,
    pub project: String,
    pub cwd: String,
    pub at_ms: i64,
    #[serde(default)] pub ask: bool,
    pub event: PulseEvent,
}

#[derive(Debug, Clone, Copy, PartialEq, Eq, Serialize, Deserialize)]
#[serde(rename_all = "lowercase")]
pub enum Decision { Allow, Deny, None }

#[derive(Debug, Clone, Copy, Serialize, Deserialize)]
pub struct Reply { pub decision: Decision }

pub fn project_name(cwd: &str) -> String {
    cwd.trim_end_matches(['\\', '/']).rsplit(['\\', '/']).next().filter(|s| !s.is_empty()).unwrap_or("sesión").to_string()
}

fn truncate(s: &str) -> String { s.chars().take(MAX_TEXT).collect() }

fn tool_target(tool: &str, input: Option<&Value>) -> String {
    let f = |k: &str| input.and_then(|v| v.get(k)).and_then(Value::as_str).map(str::to_string);
    truncate(&match tool {
        "Bash" | "PowerShell" => f("command"),
        "Read" | "Edit" | "Write" | "MultiEdit" | "NotebookEdit" => f("file_path"),
        "Grep" | "Glob" => f("pattern"),
        "Agent" | "Task" => f("description"),
        "WebFetch" => f("url"),
        "WebSearch" => f("query"),
        _ => None,
    }.unwrap_or_default())
}

pub fn map_hook(i: &HookInput) -> Option<PulseEvent> {
    let tool = i.tool_name.clone().unwrap_or_default();
    Some(match i.hook_event_name.as_str() {
        "SessionStart" => PulseEvent::SessionStart,
        "SessionEnd" => PulseEvent::SessionEnd,
        "UserPromptSubmit" => PulseEvent::Start { prompt: truncate(i.prompt.as_deref().unwrap_or("")) },
        "PreToolUse" => PulseEvent::Tool { target: tool_target(&tool, i.tool_input.as_ref()), tool },
        "PermissionRequest" => PulseEvent::Permission { command: tool_target(&tool, i.tool_input.as_ref()), tool },
        "Notification" if i.notification_type.as_deref() == Some("idle_prompt") => PulseEvent::Idle,
        "Stop" => PulseEvent::Done,
        "PostToolUseFailure" => PulseEvent::Error { message: truncate(i.error.as_deref().unwrap_or("falló una herramienta")) },
        "SubagentStart" => PulseEvent::SubagentStart { agent: i.agent_type.clone().unwrap_or_default() },
        "SubagentStop" => PulseEvent::SubagentStop { agent: i.agent_type.clone().unwrap_or_default() },
        _ => return None,
    })
}

pub fn envelope_from_hook(i: &HookInput, at_ms: i64, ask: bool) -> Option<Envelope> {
    Some(Envelope { v: PROTOCOL_VERSION, session_id: i.session_id.clone(), project: project_name(&i.cwd), cwd: i.cwd.clone(), at_ms, ask, event: map_hook(i)? })
}

pub fn is_dangerous(cmd: &str) -> bool {
    let c = cmd.to_lowercase();
    ["push --force", "push -f", "rm -rf", "rm -r ", "migrate", "reset --hard", "remove-item -recurse", "drop table", "drop database", "format "]
        .iter().any(|p| c.contains(p))
}

/// JSON que `pulse ask` imprime para Claude Code. `None` = no decidir (Claude pregunta en la terminal).
pub fn permission_output(d: Decision) -> Option<String> {
    let behavior = match d { Decision::Allow => "allow", Decision::Deny => "deny", Decision::None => return None };
    let mut decision = json!({ "behavior": behavior });
    if d == Decision::Deny { decision["message"] = json!("Denegado desde Pulse"); }
    Some(json!({ "hookSpecificOutput": { "hookEventName": "PermissionRequest", "decision": decision } }).to_string())
}
```

```rust
use std::{fs::{File, OpenOptions}, io::{BufRead, BufReader, Write}, path::Path, process::{Command, Stdio}, sync::mpsc, thread, time::{Duration, Instant}};

const ERROR_FILE_NOT_FOUND: i32 = 2;
const ERROR_PIPE_BUSY: i32 = 231;
const DETACHED_PROCESS: u32 = 0x0000_0008;
const CREATE_NEW_PROCESS_GROUP: u32 = 0x0000_0200;

fn try_open(pipe: &str) -> std::io::Result<File> { OpenOptions::new().read(true).write(true).open(pipe) }

fn spawn_app(app: &Path) -> Result<(), String> {
    use std::os::windows::process::CommandExt;
    Command::new(app).creation_flags(DETACHED_PROCESS | CREATE_NEW_PROCESS_GROUP)
        .stdin(Stdio::null()).stdout(Stdio::null()).stderr(Stdio::null())
        .spawn().map(|_| ()).map_err(|e| format!("no se pudo lanzar {}: {e}", app.display()))
}

/// Abre el pipe. Si nadie escucha y hay `app`, la lanza y reintenta hasta 3 s.
pub fn open(pipe: &str, app: Option<&Path>) -> Result<File, String> {
    match try_open(pipe) {
        Ok(f) => return Ok(f),
        Err(e) if e.raw_os_error() == Some(ERROR_FILE_NOT_FOUND) => match app { Some(a) => spawn_app(a)?, None => return Err("no hay servidor".into()) },
        Err(e) if e.raw_os_error() == Some(ERROR_PIPE_BUSY) => {}
        Err(e) => return Err(e.to_string()),
    }
    let deadline = Instant::now() + Duration::from_millis(3000);
    while Instant::now() < deadline {
        thread::sleep(Duration::from_millis(80));
        if let Ok(f) = try_open(pipe) { return Ok(f); }
    }
    Err("la app no respondió".into())
}

pub fn send_line(pipe: &str, line: &str, app: Option<&Path>) -> Result<(), String> {
    open(pipe, app)?.write_all(line.as_bytes()).map_err(|e| e.to_string())
}

/// Manda `line` y espera una línea de respuesta hasta `timeout`. `None` si no hubo respuesta.
pub fn request(pipe: &str, line: &str, app: Option<&Path>, timeout: Duration) -> Option<String> {
    let mut f = open(pipe, app).ok()?;
    f.write_all(line.as_bytes()).ok()?;
    let (tx, rx) = mpsc::channel();
    thread::spawn(move || { let mut s = String::new(); if BufReader::new(f).read_line(&mut s).is_ok() && !s.is_empty() { let _ = tx.send(s); } });
    rx.recv_timeout(timeout).ok().map(|s| s.trim_end().to_string())
}
```

```rust
use std::collections::{BTreeMap, VecDeque};
use pulse_protocol::{is_dangerous, Envelope, PulseEvent};
use serde::Serialize;

pub const IDLE_EXIT_MS: i64 = 5 * 60_000;
pub const STALE_SESSION_MS: i64 = 2 * 3_600_000;
const FEED_MAX: usize = 40;

#[derive(Debug, Clone, Copy, PartialEq, Eq, PartialOrd, Ord, Serialize)]
pub enum SessionState { Idle, Done, Working, IdleWait, Waiting }

#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum Cue { Start, Permission, Done, Idle, Error, Subagent }

impl Cue { pub fn key(self) -> &'static str { match self { Cue::Start => "start", Cue::Permission => "permission", Cue::Done => "done", Cue::Idle => "idle", Cue::Error => "error", Cue::Subagent => "subagent" } } }

#[derive(Debug, Clone, Serialize)]
pub struct Session { pub id: String, pub project: String, pub slot: u8, pub state: SessionState, pub last: String, pub subagents: u32, pub since_ms: i64, pub last_event_ms: i64, pub actions: u32, pub muted_until_ms: i64 }
#[derive(Debug, Clone, Serialize)]
pub struct Pending { pub id: u64, pub session_id: String, pub project: String, pub tool: String, pub command: String, pub danger: bool, pub at_ms: i64, pub timeout_ms: i64 }
#[derive(Debug, Clone, Serialize)]
pub struct FeedItem { pub session_id: String, pub project: String, pub text: String, pub at_ms: i64 }
#[derive(Debug, Clone, Serialize)]
pub struct Deferred { pub session_id: String, pub project: String, pub kind: String }
#[derive(Debug, Clone, Serialize)]
pub struct Snapshot { pub sessions: Vec<Session>, pub pending: Vec<Pending>, pub feed: Vec<FeedItem>, pub focus: bool, pub focus_auto: bool, pub deferred: Vec<Deferred> }

#[derive(Debug, Default)]
pub struct Store {
    sessions: BTreeMap<String, Session>,
    pending: Vec<Pending>,
    feed: VecDeque<FeedItem>,
    deferred: Vec<Deferred>,
    focus_manual: Option<bool>,
    focus_auto: bool,
    last_event_ms: i64,
}

impl Store {
    fn free_slot(&self) -> u8 { (0u8..).find(|n| !self.sessions.values().any(|s| s.slot == *n)).unwrap() }

    pub fn focus(&self) -> bool { self.focus_manual.unwrap_or(self.focus_auto) }

    pub fn apply(&mut self, e: &Envelope) -> Option<Cue> {
        self.last_event_ms = self.last_event_ms.max(e.at_ms);
        if e.event == PulseEvent::SessionEnd { self.sessions.remove(&e.session_id); self.pending.retain(|p| p.session_id != e.session_id); return None; }
        let slot = self.free_slot();
        let s = self.sessions.entry(e.session_id.clone()).or_insert_with(|| Session {
            id: e.session_id.clone(), project: e.project.clone(), slot, state: SessionState::Idle, last: String::new(),
            subagents: 0, since_ms: e.at_ms, last_event_ms: e.at_ms, actions: 0, muted_until_ms: 0 });
        s.last_event_ms = e.at_ms;
        let set = |s: &mut Session, st: SessionState| if s.state != st { s.state = st; s.since_ms = e.at_ms; };
        let (cue, feed) = match &e.event {
            PulseEvent::SessionStart | PulseEvent::SessionEnd => (None, None),
            PulseEvent::Start { prompt } => { set(s, SessionState::Working); s.last = prompt.clone(); s.actions += 1; (Some(Cue::Start), Some(format!("Prompt {prompt}"))) }
            PulseEvent::Tool { tool, target } => {
                if s.state != SessionState::Waiting { set(s, SessionState::Working); }
                s.last = if target.is_empty() { tool.clone() } else { format!("{tool} {target}") };
                s.actions += 1;
                (None, Some(s.last.clone()))
            }
            PulseEvent::Permission { command, .. } => { set(s, SessionState::Waiting); s.last = command.clone(); (Some(Cue::Permission), Some(format!("Permiso {command}"))) }
            PulseEvent::Idle => { set(s, SessionState::IdleWait); (Some(Cue::Idle), None) }
            PulseEvent::Done => { set(s, SessionState::Done); s.subagents = 0; (Some(Cue::Done), Some("Terminó".into())) }
            PulseEvent::Error { message } => { s.last = format!("Falló: {message}"); (Some(Cue::Error), Some(format!("Error {message}"))) }
            PulseEvent::SubagentStart { agent } => { s.subagents += 1; set(s, SessionState::Working); (None, Some(format!("Agent {agent}"))) }
            PulseEvent::SubagentStop { agent } => { s.subagents = s.subagents.saturating_sub(1); (Some(Cue::Subagent), Some(format!("Agent terminó: {agent}"))) }
        };
        if let Some(text) = feed {
            self.feed.push_front(FeedItem { session_id: e.session_id.clone(), project: e.project.clone(), text, at_ms: e.at_ms });
            self.feed.truncate(FEED_MAX);
        }
        cue
    }

    pub fn add_pending(&mut self, id: u64, e: &Envelope, timeout_ms: i64) {
        if let PulseEvent::Permission { tool, command } = &e.event {
            self.pending.push(Pending { id, session_id: e.session_id.clone(), project: e.project.clone(), tool: tool.clone(), command: command.clone(), danger: is_dangerous(command), at_ms: e.at_ms, timeout_ms });
        }
    }

    pub fn resolve(&mut self, id: u64) -> Option<Pending> {
        let i = self.pending.iter().position(|p| p.id == id)?;
        let p = self.pending.remove(i);
        if let Some(s) = self.sessions.get_mut(&p.session_id) { if !self.pending.iter().any(|q| q.session_id == p.session_id) { s.state = SessionState::Working; } }
        Some(p)
    }

    pub fn expire(&mut self, now_ms: i64) -> Vec<u64> {
        self.pending.iter().filter(|p| now_ms - p.at_ms >= p.timeout_ms).map(|p| p.id).collect()
    }

    pub fn set_focus(&mut self, manual: Option<bool>, auto: bool) -> Vec<Deferred> {
        let was = self.focus();
        if manual.is_some() { self.focus_manual = manual; }
        self.focus_auto = auto;
        if was && !self.focus() { std::mem::take(&mut self.deferred) } else { Vec::new() }
    }

    pub fn defer(&mut self, e: &Envelope, kind: &str) { self.deferred.push(Deferred { session_id: e.session_id.clone(), project: e.project.clone(), kind: kind.into() }); }

    pub fn mute(&mut self, session_id: &str, until_ms: i64) { if let Some(s) = self.sessions.get_mut(session_id) { s.muted_until_ms = until_ms; } }

    pub fn is_muted(&self, session_id: &str, now_ms: i64) -> bool { self.sessions.get(session_id).is_some_and(|s| s.muted_until_ms > now_ms) }

    pub fn slot_of(&self, session_id: &str) -> u8 { self.sessions.get(session_id).map(|s| s.slot).unwrap_or(0) }

    pub fn aggregate(&self) -> SessionState { self.sessions.values().map(|s| s.state).max().unwrap_or(SessionState::Idle) }

    pub fn summary(&self) -> String {
        if self.sessions.is_empty() { return "Pulse · sin sesiones".into(); }
        let w = self.sessions.values().filter(|s| s.state == SessionState::Working).count();
        let n = self.sessions.values().filter(|s| matches!(s.state, SessionState::Waiting | SessionState::IdleWait)).count();
        let mut out = String::from("Pulse");
        if w > 0 { out += &format!(" · {w} trabajando"); }
        if n > 0 { out += &format!(" · {n} te necesita{}", if n > 1 { "n" } else { "" }); }
        if w == 0 && n == 0 { out += &format!(" · {} en calma", self.sessions.len()); }
        out
    }

    pub fn should_exit(&mut self, now_ms: i64) -> bool {
        let mut freed_at = self.last_event_ms;
        self.sessions.retain(|_, s| { let alive = now_ms - s.last_event_ms < STALE_SESSION_MS; if !alive { freed_at = freed_at.max(s.last_event_ms + STALE_SESSION_MS); } alive });
        self.sessions.is_empty() && self.pending.is_empty() && now_ms - freed_at >= IDLE_EXIT_MS
    }

    pub fn snapshot(&self) -> Snapshot {
        let mut sessions: Vec<Session> = self.sessions.values().cloned().collect();
        sessions.sort_by_key(|s| s.slot);
        Snapshot { sessions, pending: self.pending.clone(), feed: self.feed.iter().cloned().collect(), focus: self.focus(), focus_auto: self.focus_auto, deferred: self.deferred.clone() }
    }
}
```

```rust
use pulse_protocol::{Decision, Envelope, Reply};
use tokio::{io::{AsyncBufReadExt, AsyncWriteExt, BufReader}, net::windows::named_pipe::{NamedPipeServer, ServerOptions}, sync::{mpsc::UnboundedSender, oneshot}};

pub struct Incoming { pub env: Envelope, pub reply: Option<oneshot::Sender<Decision>> }

pub fn create_first(name: &str) -> std::io::Result<NamedPipeServer> { ServerOptions::new().first_pipe_instance(true).create(name) }

pub async fn serve(first: NamedPipeServer, name: String, tx: UnboundedSender<Incoming>) {
    let mut server = first;
    loop {
        if server.connect().await.is_err() { continue; }
        let conn = server;
        server = match ServerOptions::new().create(&name) { Ok(s) => s, Err(_) => return };
        let tx = tx.clone();
        tokio::spawn(async move {
            let (r, mut w) = tokio::io::split(conn);
            let mut lines = BufReader::new(r).lines();
            while let Ok(Some(line)) = lines.next_line().await {
                let Ok(env) = serde_json::from_str::<Envelope>(line.trim()) else { continue };
                if env.ask {
                    let (otx, orx) = oneshot::channel();
                    if tx.send(Incoming { env, reply: Some(otx) }).is_err() { return; }
                    let decision = orx.await.unwrap_or(Decision::None);
                    let out = serde_json::to_string(&Reply { decision }).unwrap() + "\n";
                    let _ = w.write_all(out.as_bytes()).await;
                    return;
                }
                let _ = tx.send(Incoming { env, reply: None });
            }
        });
    }
}
```

`sound.rs`: igual que la descripción siguiente. Reproductor en hilo propio con `rodio::OutputStream::try_default()`; cola `mpsc::Sender<(Cue, f32 /*volumen 0..1*/)>`; ignora el mismo `Cue` repetido en < 300 ms; `start/permission/done/idle` desde `include_bytes!("../../../assets/sounds/<x>.wav")` con `Decoder::new(Cursor::new(bytes))` y `.amplify(volumen)`; `Error` = `SineWave::new(220.0)` 90 ms + `SineWave::new(170.0)` 120 ms a 0.18 × volumen; `Subagent` = `SineWave::new(1320.0)` 60 ms + `SineWave::new(1760.0)` 70 ms a 0.08 × volumen. API: `Player::start() -> Player`, `Player::play(&self, cue: Cue, volume: f32)`.

```rust
use crate::state::Cue;
use rodio::{source::{SineWave, Source}, Decoder, OutputStream, Sink};
use std::{collections::HashMap, io::Cursor, sync::mpsc, time::{Duration, Instant}};
static START: &[u8] = include_bytes!("../../../assets/sounds/start.wav");
static PERMISSION: &[u8] = include_bytes!("../../../assets/sounds/permission.wav");
static DONE: &[u8] = include_bytes!("../../../assets/sounds/done.wav");
static IDLE: &[u8] = include_bytes!("../../../assets/sounds/idle.wav");
pub struct Player { tx: mpsc::Sender<(Cue, f32)> }
impl Player {
    pub fn start() -> Player {
        let (tx, rx) = mpsc::channel::<(Cue, f32)>();
        std::thread::spawn(move || {
            let Ok((_stream, handle)) = OutputStream::try_default() else { return };
            let mut last: HashMap<&'static str, Instant> = HashMap::new();
            for (cue, vol) in rx {
                if last.get(cue.key()).is_some_and(|t| t.elapsed() < Duration::from_millis(300)) { continue; }
                last.insert(cue.key(), Instant::now());
                let Ok(sink) = Sink::try_new(&handle) else { continue };
                let wav = |b: &'static [u8]| Decoder::new(Cursor::new(b)).ok().map(|d| d.amplify(vol));
                let tone = |f: f32, ms: u64, g: f32| SineWave::new(f).take_duration(Duration::from_millis(ms)).amplify(g * vol);
                match cue {
                    Cue::Start => if let Some(d) = wav(START) { sink.append(d) },
                    Cue::Permission => if let Some(d) = wav(PERMISSION) { sink.append(d) },
                    Cue::Done => if let Some(d) = wav(DONE) { sink.append(d) },
                    Cue::Idle => if let Some(d) = wav(IDLE) { sink.append(d) },
                    Cue::Error => { sink.append(tone(220.0, 90, 0.18)); sink.append(tone(170.0, 120, 0.18)); }
                    Cue::Subagent => { sink.append(tone(1320.0, 60, 0.08)); sink.append(tone(1760.0, 70, 0.08)); }
                }
                sink.detach();
            }
        });
        Player { tx }
    }
    pub fn play(&self, cue: Cue, volume: f32) { let _ = self.tx.send((cue, volume)); }
}
```

```rust
pub fn broadcast(app: &AppHandle) {

/// Resuelve un permiso pendiente: contesta a `pulse ask`, registra y avisa a las ventanas.
pub fn resolve(app: &AppHandle, id: u64, decision: Decision) {
    let st = app.state::<AppState>();
    let pending = st.store.lock().unwrap().resolve(id);
    if let Some(tx) = st.waiters.lock().unwrap().remove(&id) { let _ = tx.send(decision); }
    if let Some(p) = pending {
        logbook::append_resolve(&p.session_id, &p.project, id, match decision { Decision::Allow => Some(true), Decision::Deny => Some(false), Decision::None => None }, now_ms());
        emit_fx(app, Fx { kind: "resolved".into(), session_id: p.session_id, project: p.project, slot: 0, text: format!("{}|{}", match decision { Decision::Allow => "allow", Decision::Deny => "deny", Decision::None => "none" }, p.command), visual: false, sound: false });
    }
    broadcast(app);
}

fn handle(app: &AppHandle, inc: server::Incoming) {
    let st = app.state::<AppState>();
    let env = inc.env;
    logbook::append(&env);
    let cfg = st.config.lock().unwrap().clone();
    let (cue, focus_on, muted, slot) = { let mut s = st.store.lock().unwrap(); let c = s.apply(&env); (c, s.focus(), s.is_muted(&env.session_id, now_ms()), s.slot_of(&env.session_id)) };
    if let Some(reply) = inc.reply {
        let id = st.next_id.fetch_add(1, Ordering::SeqCst) + 1;
        st.store.lock().unwrap().add_pending(id, &env, cfg.island.ask_timeout_s as i64 * 1000);
        st.waiters.lock().unwrap().insert(id, reply);
    }
    if let Some(cue) = cue {
        let kind = cue.key();
        let mut r = config::route(&cfg, focus_on, kind);
        if muted && cue != Cue::Permission { r.sound = false; r.visual = false; }
        if r.defer { st.store.lock().unwrap().defer(&env, kind); }
        if r.sound { st.player.play(cue, cfg.sounds.volume as f32 / 100.0); }
        let text = match &env.event { PulseEvent::Error { message } => message.clone(), PulseEvent::Permission { command, .. } => command.clone(), _ => String::new() };
        emit_fx(app, Fx { kind: kind.into(), session_id: env.session_id.clone(), project: env.project.clone(), slot, text, visual: r.visual, sound: r.sound });
        if r.visual { chroma::pulse(app, kind, slot); }
    }
    broadcast(app);
}
```

```ts
  if (noise) return noise;
  const c = document.createElement('canvas'); c.width = c.height = 96; const x = c.getContext('2d')!; const d = x.createImageData(96, 96);
  for (let i = 0; i < d.data.length; i += 4) { const v = Math.random() * 255; d.data[i] = d.data[i + 1] = d.data[i + 2] = v; d.data[i + 3] = 255; }
  x.putImageData(d, 0, 0); return (noise = c.toDataURL());
}
export interface EngineOpts { crisp: boolean; corners: boolean; adapt: boolean; dither: boolean; lightBackground: boolean; reduce: boolean }
export function pulse(layer: HTMLElement, cfg: PulseCfg, g: Geo, o: EngineOpts) {
  const t = Math.max(4, cfg.thickness), I = cfg.intensity / 100, D = cfg.duration_ms;
  const shape = o.reduce ? 'respira' : cfg.shape, side = shape === 'lateral' ? g.side : undefined;
  let c = cfg.color;
  const wrap = document.createElement('div'); wrap.style.cssText = 'position:absolute;inset:0;pointer-events:none';
  if (o.adapt && o.lightBackground) { c = darken(c, .18); wrap.style.mixBlendMode = 'multiply'; }
  const paint = paintFor(shape, c, g);
  const add = (mask: string, op: number) => { const e = document.createElement('div'); e.style.cssText = `position:absolute;inset:0;opacity:${op}`; e.style.background = paint; setMask(e, mask); wrap.appendChild(e); };
  add(edgeMask(side ? t * 1.3 : t, side), .82);
  if (o.crisp) add(lineMask(side), 1);
  if (o.corners && !side) add(cornerMask(t), .45);
  if (o.dither) { const n = document.createElement('div'); n.style.cssText = `position:absolute;inset:0;background:url(${noiseURL()});mix-blend-mode:overlay;opacity:.5`; setMask(n, edgeMask(t, side)); wrap.appendChild(n); }
  layer.appendChild(wrap);
  const a = wrap.animate(keyframesFor(shape, I, g), { duration: D, easing: 'linear' });
  const kill = () => wrap.remove(); a.onfinish = kill; setTimeout(kill, D + 400);
}
const residuals = new Map<string, HTMLElement>();
export function residualOn(key: string, layer: HTMLElement, cfg: PulseCfg, reduce: boolean) {

  residuals.set(key, e);
}
export function residualOff(key: string, instant = false) {
  const e = residuals.get(key); if (!e) return; residuals.delete(key);
  if (instant) return e.remove();
  e.getAnimations().forEach(a => a.pause());
  e.animate([{ opacity: getComputedStyle(e).opacity }, { opacity: 0 }], { duration: 450 }).onfinish = () => e.remove();
}
```

```rust
use serde::Serialize;
use std::collections::BTreeMap;

#[derive(Debug, Clone, Serialize, Default)]
pub struct SessionDay { pub project: String, pub work_ms: i64, pub waited_ms: i64, pub max_wait_ms: i64, pub perms: u32, pub errors: u32, pub subagents: u32, pub actions: u32, pub lanes: Vec<(f64, f64, char)> }
#[derive(Debug, Clone, Serialize, Default)]
pub struct DaySummary { pub sessions: Vec<SessionDay>, pub total_work_ms: i64, pub total_waited_ms: i64, pub actions_by_hour: [u32; 24] }

#[derive(Default)] struct Open { work: Option<i64>, wait: Option<i64> }

pub fn summarize(lines: impl Iterator<Item = String>, day_start_ms: i64, now_ms: i64) -> DaySummary {
    let span = (now_ms - day_start_ms).max(1) as f64;
    let frac = |t: i64| (t - day_start_ms) as f64 / span;
    let mut days: BTreeMap<String, (SessionDay, Open)> = BTreeMap::new();
    let mut out = DaySummary::default();
    for line in lines {
        let Ok(v) = serde_json::from_str::<serde_json::Value>(&line) else { continue };
        let (Some(sid), Some(at), Some(kind)) = (v["session_id"].as_str(), v["at_ms"].as_i64(), v["event"]["kind"].as_str()) else { continue };
        if at < day_start_ms || at > now_ms { continue; }
        let (d, o) = days.entry(sid.to_string()).or_default();
        if d.project.is_empty() { d.project = v["project"].as_str().unwrap_or("sesión").to_string(); }
        let close_wait = |d: &mut SessionDay, o: &mut Open, t: i64| if let Some(w) = o.wait.take() { d.waited_ms += t - w; d.max_wait_ms = d.max_wait_ms.max(t - w); d.lanes.push((frac(w), frac(t), 'p')); };
        match kind {
            "start" => { close_wait(d, o, at); if o.work.is_none() { o.work = Some(at); } d.actions += 1; out.actions_by_hour[((at - day_start_ms) / 3_600_000).clamp(0, 23) as usize] += 1; }
            "tool" => { if o.work.is_none() { o.work = Some(at); } d.actions += 1; out.actions_by_hour[((at - day_start_ms) / 3_600_000).clamp(0, 23) as usize] += 1; }
            "permission" => { d.perms += 1; o.wait = Some(at); if o.work.is_none() { o.work = Some(at); } }
            "resolve" => close_wait(d, o, at),
            "done" => { close_wait(d, o, at); if let Some(w) = o.work.take() { d.work_ms += at - w; d.lanes.push((frac(w), frac(at), 'w')); } }
            "error" => { d.errors += 1; d.lanes.push((frac(at), frac(at), 'e')); }
            "subagent-stop" => d.subagents += 1,
            _ => {}
        }
    }
    for (_, (mut d, mut o)) in days {
        if let Some(w) = o.wait.take() { d.waited_ms += now_ms - w; d.max_wait_ms = d.max_wait_ms.max(now_ms - w); d.lanes.push((frac(w), 1.0, 'p')); }
        if let Some(w) = o.work.take() { d.work_ms += now_ms - w; d.lanes.push((frac(w), 1.0, 'w')); }
        out.total_work_ms += d.work_ms; out.total_waited_ms += d.waited_ms;
        out.sessions.push(d);
    }
    out
}

pub fn today() -> DaySummary {
    let now = crate::now_ms();
    let start = local_midnight_ms(now);
    let lines = crate::logbook::path().and_then(|p| std::fs::read_to_string(p).ok()).unwrap_or_default();
    summarize(lines.lines().map(str::to_string), start, now)
}

fn local_midnight_ms(now_ms: i64) -> i64 {
    use windows_sys::Win32::System::Time::{GetTimeZoneInformation, TIME_ZONE_INFORMATION};
    let mut tz: TIME_ZONE_INFORMATION = unsafe { std::mem::zeroed() };
    unsafe { GetTimeZoneInformation(&mut tz) };
    let offset_ms = -(tz.Bias as i64) * 60_000;   // Bias está en minutos, UTC = local + Bias
    let local = now_ms + offset_ms;
    local - local.rem_euclid(86_400_000) - offset_ms
}
```

```rust
/// Micrófono en uso por otra app: alguna entrada de ConsentStore con LastUsedTimeStop == 0.
pub fn mic_in_use() -> bool {
    use windows_sys::Win32::System::Registry::*;
    unsafe fn any_active(root: HKEY, path: &str) -> bool {
        let wide: Vec<u16> = path.encode_utf16().chain(Some(0)).collect();
        let mut key: HKEY = std::ptr::null_mut();
        if RegOpenKeyExW(root, wide.as_ptr(), 0, KEY_READ, &mut key) != 0 { return false; }
        let mut i = 0u32; let mut found = false;
        loop {
            let mut name = [0u16; 512]; let mut len = name.len() as u32;
            if RegEnumKeyExW(key, i, name.as_mut_ptr(), &mut len, std::ptr::null_mut(), std::ptr::null_mut(), std::ptr::null_mut(), std::ptr::null_mut()) != 0 { break; }
            let sub = String::from_utf16_lossy(&name[..len as usize]);
            if sub == "NonPackaged" { if any_active(root, &format!("{path}\\NonPackaged")) { found = true; break; } }
            else {
                let sw: Vec<u16> = format!("{path}\\{sub}").encode_utf16().chain(Some(0)).collect();
                let vname: Vec<u16> = "LastUsedTimeStop".encode_utf16().chain(Some(0)).collect();
                let mut v: u64 = 1; let mut sz = 8u32;
                if RegGetValueW(root, sw.as_ptr(), vname.as_ptr(), RRF_RT_REG_QWORD, std::ptr::null_mut(), &mut v as *mut _ as _, &mut sz) == 0 && v == 0 { found = true; break; }
            }
            i += 1;
        }
        RegCloseKey(key);
        found
    }
    unsafe { any_active(HKEY_CURRENT_USER, r"Software\Microsoft\Windows\CurrentVersion\CapabilityAccessManager\ConsentStore\microphone") }
}
```

```rust
pub struct KeyFx { pub shape: String, pub color: [u8; 3], pub intensity: f32, pub start_ms: i64, pub dur_ms: i64, pub ox: f32, pub oy: f32, pub left: bool }
static URI: OnceLock<Mutex<Option<String>>> = OnceLock::new();
static FX: OnceLock<Mutex<Vec<KeyFx>>> = OnceLock::new();
fn uri() -> &'static Mutex<Option<String>> { URI.get_or_init(|| Mutex::new(None)) }
fn fxs() -> &'static Mutex<Vec<KeyFx>> { FX.get_or_init(|| Mutex::new(Vec::new())) }

pub fn bgr(c: [u8; 3]) -> u32 { (c[2] as u32) << 16 | (c[1] as u32) << 8 | c[0] as u32 }
fn lerp(pts: &[(f32, f32)], p: f32) -> f32 { for w in pts.windows(2) { if p <= w[1].0 { return w[0].1 + (w[1].1 - w[0].1) * (p - w[0].0) / (w[1].0 - w[0].0); } } 0.0 }

/// Port de `fxAt` del diseño original. x, y, ox, oy en 0..1; p progreso 0..1.
pub fn fx_at(shape: &str, x: f32, y: f32, ox: f32, oy: f32, left: bool, i: f32, p: f32) -> f32 {
    match shape {
        "latido" => i * lerp(&[(0.0, 0.0), (0.12, 1.0), (0.32, 0.1), (0.46, 0.9), (1.0, 0.0)], p),
        "lateral" => if (left && x < 0.16) || (!left && x > 0.84) { i * lerp(&[(0.0, 0.0), (0.1, 1.0), (0.25, 0.2), (0.4, 1.0), (1.0, 0.0)], p) } else { 0.0 },
        "ola" => { let d = if left { x } else { 1.0 - x }; let fr = -0.1 + p * 1.25; let fd = if p < 0.15 { p / 0.15 } else if p > 0.85 { (1.0 - p) / 0.15 } else { 1.0 }; i * (-((d - fr) / 0.08).powi(2)).exp() * fd }
        "barrido" => i * (-((y - (1.15 - 1.3 * p)) / 0.16).powi(2)).exp(),
        "origen" => { let d = ((x - ox).powi(2) + ((y - oy) * 0.38).powi(2)).sqrt(); i * (-((d - p * 1.15) / 0.05).powi(2)).exp() * (1.0 - p).powf(0.6) + if d < 0.03 && p < 0.3 { i * (1.0 - p / 0.3) } else { 0.0 } }
        _ => i * if p < 0.35 { p / 0.35 } else { (1.0 - p) / 0.65 },
    }
}

pub fn grid(base: [u8; 3], level: f32, fx: &[KeyFx], waiting: &[(u8, [u8; 3])], session_keys: bool, now_ms: i64) -> [[u32; COLS]; ROWS] {
    let mut g = [[0u32; COLS]; ROWS];
    let breath = 0.5 + 0.5 * ((now_ms as f32) / 600.0).sin();
    for r in 0..ROWS { for c in 0..COLS {
        let (x, y) = (c as f32 / (COLS - 1) as f32, r as f32 / (ROWS - 1) as f32);
        let mut best = (level, base);
        for f in fx { let p = ((now_ms - f.start_ms) as f32 / f.dur_ms as f32).clamp(0.0, 1.0); let v = fx_at(&f.shape, x, y, f.ox, f.oy, f.left, f.intensity, p); if v > best.0 { best = (v, f.color); } }
        if session_keys && r == 0 { for (slot, col) in waiting { if c == 3 + *slot as usize { let v = 0.35 + 0.5 * breath; if v > best.0 { best = (v, *col); } } } }
        let k = best.0.clamp(0.0, 1.0);
        g[r][c] = if k <= 0.0 { 0 } else { bgr([(best.1[0] as f32 * k) as u8, (best.1[1] as f32 * k) as u8, (best.1[2] as f32 * k) as u8]) };
    } }
    g
}

fn put(path: &str, body: serde_json::Value) { if let Some(u) = uri().lock().unwrap().clone() { let _ = ureq::put(&format!("{u}{path}")).send_json(body); } }

pub fn start(app: &AppHandle) {
    if !app.state::<AppState>().config.lock().unwrap().keyboard.enabled { return; }
    let a = app.clone();
    std::thread::spawn(move || {
        let init = serde_json::json!({ "title": "Pulse", "description": "Avisos de Claude Code", "author": { "name": "Pulse", "contact": "local" }, "device_supported": ["keyboard"], "category": "application" });
        let Ok(resp) = ureq::post("http://localhost:54235/razer/chromasdk").send_json(init) else { return };   // Chroma no instalado: no hacer nada
        let Ok(v) = resp.into_json::<serde_json::Value>() else { return };
        *uri().lock().unwrap() = v["uri"].as_str().map(str::to_string);
        std::thread::sleep(std::time::Duration::from_millis(500));   // Chroma necesita un momento tras el init
        let mut last_beat = std::time::Instant::now();
        loop {
            let st = a.state::<AppState>();
            let kb = st.config.lock().unwrap().keyboard.clone();
            let snap = st.store.lock().unwrap().snapshot();
            let now = crate::now_ms();
            fxs().lock().unwrap().retain(|f| now - f.start_ms < f.dur_ms);
            let waiting: Vec<(u8, [u8; 3])> = snap.sessions.iter().filter_map(|s| match s.state {
                crate::state::SessionState::Waiting => Some((s.slot, [255, 176, 46])), crate::state::SessionState::IdleWait => Some((s.slot, [182, 192, 212])), _ => None }).collect();
            let g = if kb.enabled { grid([120, 140, 175], kb.base as f32 / 200.0, &fxs().lock().unwrap(), &waiting, kb.session_keys, now) } else { [[0; COLS]; ROWS] };
            put("/keyboard", serde_json::json!({ "effect": "CHROMA_CUSTOM", "param": g }));
            if last_beat.elapsed().as_secs() >= 10 { put("/heartbeat", serde_json::json!({})); last_beat = std::time::Instant::now(); }
            let busy = !fxs().lock().unwrap().is_empty() || !waiting.is_empty();
            std::thread::sleep(std::time::Duration::from_millis(if busy { 33 } else { 1000 }));
        }
    });
}

pub fn pulse(app: &AppHandle, kind: &str, slot: u8) {
    let cfg = app.state::<AppState>().config.lock().unwrap().clone();
    if !cfg.keyboard.enabled { return; }
    let Some(p) = cfg.pulses.events.get(kind) else { return };
    let hex = u32::from_str_radix(p.color.trim_start_matches('#'), 16).unwrap_or(0xffffff);
    let ox = if cfg.keyboard.session_keys { (3 + slot as usize) as f32 / (COLS - 1) as f32 } else { [0.18, 0.5, 0.82][slot as usize % 3] };
    fxs().lock().unwrap().push(KeyFx { shape: p.shape.clone(), color: [(hex >> 16) as u8, (hex >> 8) as u8, hex as u8], intensity: p.intensity as f32 / 100.0, start_ms: crate::now_ms(), dur_ms: p.duration_ms.max(700) as i64, ox, oy: if cfg.keyboard.session_keys { 0.0 } else { 0.5 }, left: ox < 0.5 });
}
```
